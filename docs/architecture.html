System overview

Moisture reading path

Each probe measures and calibrates itself. The probe task polls every configured probe every 10 seconds over Modbus and keeps the results. Everything else reads those stored values; only the probe task and the commands from the /probes page (calibrate, change address, firmware update) use the bus, one transaction at a time.

Things to know

  • The firmware runs on one CPU core, so a task that never yields can starve the others, including Wi-Fi and HomeKit.
  • New probes all answer on address 1: add them one at a time on /probes and change the address before connecting the next.
  • Probes added or removed show up in the Home app after the controller restarts.
  • A probe firmware update pauses polling for about 30 s; the image is staged in the spare OTA partition, so controller OTA uploads are refused meanwhile.
  • A reboot caused by a crash is recorded in the event log with its reset reason, shown on the web page.
  • The web server's startup log mentions port 8081, but the control page is served by the shared server on 8080.
